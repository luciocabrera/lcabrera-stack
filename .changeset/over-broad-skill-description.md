`repo-verify-harness` reports a skill or subagent description that claims every task as a "Vague description" finding. The finding quotes the phrase that triggered it. The phrases it looks for are a quantifier over a generic noun ("any task", "every request", "all work", "any file") with no word introducing a scope after it (such as "in", "to", "for", "under", "about" or "that"), "anything else", "everything else", "at all" where it ends a clause (not "at all files"), "no matter what", and "whatever you" or "whatever the user". A quantifier over something specific still passes: "any code change", "any change to packages/ui", "any file under docs/", "any file that a workspace ships", "anything new". A noun joined to the next word by a hyphen or an apostrophe ("any file-scoped rule", "any file's frontmatter") modifies that word rather than heading the phrase, so it is not reported either. Before this change, a description that met the word floor, named a concrete token and used a trigger word was accepted even when it applied to every task.
