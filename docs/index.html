lcabrera-stack

A data-grid stack, built by agents under interlock

A TypeScript monorepo by Lucio Cabrera. It ships a React data grid with the browser and Postgres layers behind it, and the toolchain that keeps the repository honest, including the agent setup that does most of the building. It is a personal repository for practising agent-driven delivery end to end, held to the standards of a product.
