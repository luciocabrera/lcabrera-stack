# Artifact Inventory (`@lcabrera/ui`)

Before creating anything new, check this inventory. If something here does the job — or could do it with a small enhancement to make it more generic — **prefer enhancing the existing artifact** over creating a new one.

**Visibility.** Every artifact is either **Public** or a **Private delegate**, and its location tells you which:

- **Public** — exported from a barrel `index.ts` and imported across modules via `@lcabrera/ui/...`. Every top-level `components/<Name>/` entry is Public.
- **Private delegate** — nested _inside_ another component/module and imported only within that parent (everything under `components/Form/…`, `components/Table/…`, and every `*/utils/` or `hooks/utils/` helper).

Private delegates are catalogued here on purpose — reuse or lift one before writing a duplicate — but treat them as internal: prefer enhancing or relocating over importing them across unrelated modules.

Covers `packages/ui` only. Two sibling packages own what used to be listed here, split by runtime:

- **`@lcabrera/api`** (`packages/api/src/`) — browser-safe HTTP: `fetch-and-validate.util.ts`, `build-paginated-query-params.util.ts`, base-URL resolution, and the distinct-values client.
- **`@lcabrera/server`** (`packages/server/src/`) — Node-only: Postgres access (`db/env.schema.ts`, `db/get-pool.util.ts`), the generic SQL query builder (`db/query-builder/`), query filters, and the credential primitives under `crypto/` and `tokens/`.

`@lcabrera/ui` and `@lcabrera/server` each carry their own `src/INVENTORY.md`. App-local artifacts (routes, route-specific services) are tracked in each app's own `src/INVENTORY.md`.
